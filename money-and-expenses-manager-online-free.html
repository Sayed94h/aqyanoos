Some Shortcuts on the Chart (click to open)
  1. K: Thousand = 1000
  2. M: Million = 1,000,000
  3. B: Billion = 1,000,000,000
  4. T: Trillion = 1,000,000,000,000
  5. QD: Quadrillion = 1,000,000,000,000,000
  6. QT: Quintillion = 1,000,000,000,000,000,000
Examples: 15.29K is the same as 15290, 3.5M = 3500000...To convert the short number to its long version, multiply the corresponding number for the letter with the number before the letter. For example: 32.45K -> 32.45 x 1000 (k) = 32450.
